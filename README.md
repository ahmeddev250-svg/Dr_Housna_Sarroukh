# Cabinet de Gynécologie-Obstétrique — Dr Housna Sarroukh (Agdal, Rabat)

Application web bilingue (Français / Arabe avec support complet RTL) dédiée au cabinet médical du **Dr Housna Sarroukh**, Spécialiste en Gynécologie-Obstétrique à Agdal, Rabat.

## Fonctionnalités principales

- **Identité visuelle authentique** : Logo officiel extrait, palette rose framboise & anthracite, photographies réelles du cabinet et du Dr Housna Sarroukh.
- **Bilinguisme complet FR / AR (RTL)** : Bascule instantanée entre le français (`LTR`) et l'arabe (`RTL`) avec typographie dédiée (*Plus Jakarta Sans* & *Cairo*).
- **Indicateur temps réel Ouvert / Fermé** : Synchronisé sur le fuseau horaire `Africa/Casablanca` (Lundi–Vendredi 09:00–18:00 en continu, Samedi 09:00–13:00, Dimanche fermé).
- **Prise de rendez-vous interactive (créneaux de 30 min)** : Génération dynamique des créneaux disponibles et transmission pré-formatée via WhatsApp (`+212 6 39 32 47 07`).
- **Avis Google vérifiés** : Intégration de la note officielle (`4,7 / 5` sur `127 avis`), mots-clés récurrents et témoignages authentiques.

## Installation et exécution

```bash
# 1. Installer les dépendances
npm install

# 2. Lancer le serveur de développement
npm run dev

# 3. Tester sur mobile sur le réseau local
npm run dev -- --host

# 4. Compiler pour la production
npm run build
```
